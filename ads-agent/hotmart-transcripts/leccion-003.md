# Así funciona el modelo de negocios

### Cómo funciona el modelo de negocios

Este modelo se basa en la **creación y venta de productos digitales** a través de un sistema de ventas automatizado.

---

### Productos que se crean

- **Productos digitales**: cursos, libros digitales, entre otros.
- Se crean una sola vez y luego el sistema trabaja de forma automatizada.

---

### El sistema de ventas paso a paso

#### 1. Anuncios pagados

- Se publican anuncios en **Facebook** (también conocido como **Meta**) e **Instagram**.
- Ventaja clave: al publicar en Facebook, los anuncios se muestran automáticamente en **ambas plataformas**, ya que Instagram pertenece a la familia de Meta.

---

#### 2. Página de ventas

Cuando el usuario hace clic en el anuncio, llega a la **página de ventas**, que contiene:

- Una **promesa inicial** clara sobre lo que recibirá el comprador.
- Una lista de **beneficios**: qué aprenderá o recibirá.
- **Bonos** adicionales para quienes compren.
- **Testimonios** de clientes.
- Uno o varios **botones de compra** (call to action).

---

#### 3. Checkout (página de pago)

Al hacer clic en el botón de compra, el usuario llega al **checkout**, donde ingresa:

- Nombre completo
- Correo electrónico
- Número de teléfono *(en algunos casos)*
- Datos de pago:
  - Tarjeta de crédito
  - Tarjeta de débito
  - **PayPal** u otro método de pago

---

### Flujo completo del modelo

```
Anuncio (Facebook / Instagram)
        ↓
Página de ventas
        ↓
Clic en botón de compra
        ↓
Checkout (página de pago)
        ↓
Compra efectiva → Ganancia generada
```
