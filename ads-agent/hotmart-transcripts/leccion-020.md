# Cómo crear mockups de los productos

### Cómo crear mockups de los productos

---

### ¿Qué es un mockup?

- Un **mockup** es la imagen de presentación de un producto digital (como una "cajita" que ves cuando compras un producto)
- Existen mockups en distintos formatos:
  - **eBook / libro**
  - **Tablet / iPad**
  - **Computadora**
  - **iPhone / celular**
  - **Solar / otros formatos**
- Pueden ser **individuales** (una sola imagen) o **combinados** (varias imágenes unidas en una sola presentación)

---

### Herramienta utilizada: Smart Mockups (app dentro de Canva)

- La aplicación se llama **Smart Mockups**
- Se instala desde dentro de **Canva**, en la sección de **Apps**

**Pasos para instalarla:**
1. Ir a Canva
2. Hacer clic en la sección **Apps**
3. En el buscador de apps escribir: `mockup`
4. Seleccionar **Smart Mockups** e instalarla

---

### Cómo usar Smart Mockups

**Paso 1: Descargar el cover del producto**
- Ir al diseño del **cover / portada del eBook** en Canva
- Descargarlo como imagen en formato **PNG**
- Seleccionar **solo la primera página** (página actual / página número 1)

**Paso 2: Elegir el mockup deseado**
- Dentro de Smart Mockups se pueden buscar mockups por tipo, por ejemplo:
  - `book` → para formato libro/eBook
  - `iPhone` → para formato celular
  - `computer` → para formato computadora
- Explorar las opciones y seleccionar el que más guste

**Paso 3: Subir la imagen del cover**
- Dentro del mockup seleccionado, hacer clic en **subir imagen**
- Seleccionar el archivo PNG descargado previamente
- El sistema coloca automáticamente el cover dentro del mockup

**Paso 4: Guardar y descargar**
- Una vez generado el mockup, hacer clic en **descargar**
- La imagen descargada queda lista para usar en:
  - **Página web / página de ventas**
  - **Posts**
  - **Carruseles**
  - Cualquier otro material de marketing

---

### Notas importantes

- Se pueden crear **tantos mockups como se desee** en distintos formatos
- Cada formato de producto (iPhone, computadora, tablet) requiere subir una imagen adaptada a ese formato — **no todas las imágenes quedan bien en todos los mockups**
- Siempre probar distintas opciones hasta encontrar la que mejor se vea
- El resultado final depende de qué tan terminado esté el diseño del cover original
