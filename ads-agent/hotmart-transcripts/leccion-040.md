# Instalación de Optimize Press

### ¿Qué es un Plugin?

Un **plugin** es una herramienta que se instala en WordPress para permitir realizar ciertas funciones o acciones específicas.

---

### Optimize Press: El Constructor de Sitios Web

- El plugin recomendado en este curso es **Optimize Press**
- Permite construir **sitios web más profesionales**
- Ventajas mencionadas:
  - Muchas plantillas (**templates**)
  - Muy rápido
  - Fácil de usar
  - Más de 2-3 años de uso comprobado por el instructor

> Es posible usar otros constructores si ya se tiene uno, no hay ningún problema.

---

### Planes y Precios

- El plan recomendado para empezar cuesta **$99 por año** (equivale a aprox. **$8-$9 por mes**)
- Este plan permite instalar Optimize Press en **1 sitio web**
- Para empezar es suficiente, ya que se puede vender **varios productos desde un mismo sitio**
- A medida que se crece, se pueden comprar más dominios y actualizar al plan que permite **3 sitios web**

### Proceso de Compra

- El link de compra se encuentra **debajo del video**
- Pasos:
  - Ingresar correo electrónico
  - Completar datos de tarjeta de crédito u otro método de pago
  - Crear usuario con correo electrónico y contraseña
  - Descargar el archivo del **plugin de Optimize Press**

> Si hay inconvenientes para obtener el archivo, hay dos opciones:
> - Contactar al **soporte de Optimize Press**
> - Usar el **link de descarga directa** disponible debajo del video

---

### Instalación del Plugin en WordPress

1. Ir al menú **Plugins** en el panel de WordPress
2. Hacer clic en **Añadir plugin**
3. Hacer clic en el botón **Subir plugin**
4. Hacer clic en **Seleccionar archivo** y buscar el archivo descargado de Optimize Press
5. Hacer clic en **Instalar** (puede tardar un momento dependiendo de la velocidad de internet)
6. Una vez instalado, hacer clic en **Activar plugin**

---

### Conexión con la Cuenta de Optimize Press

1. Hacer clic en la opción para **conectar el plugin con la cuenta**
2. Ingresar el **correo electrónico** y **contraseña** usados al comprar el plugin
3. Esperar que se establezca la conexión
4. Hacer clic en **Instalar** el componente adicional de Optimize Press
5. Una vez instalado, hacer clic nuevamente en **Activar**
