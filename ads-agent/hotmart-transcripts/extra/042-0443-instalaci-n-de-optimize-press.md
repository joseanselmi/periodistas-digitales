# Instalación de Optimize Press

## Introducción

**Optimize Press** es un **plugin constructor de sitios web** para WordPress que permite construir sitios web profesionales de manera fácil y rápida.

### Características principales

- Muchas plantillas disponibles
- Muy rápido de usar
- Fácil de utilizar
- Experiencia probada: más de 2-3 años de uso

## Adquisición del Plugin

### Precios y planes

- **Plan recomendado inicial**: $99 USD por año
- **Desglose mensual**: aproximadamente $8-9 USD por mes ($98.99 anuales)
- Permite instalar en **1 sitio web**
- Puedes vender varios productos en un mismo sitio

### Planes escalables

A medida que creces puedes:
- Comprar versiones con más dominios
- Acceder a planes para 3 sitios web
- Expandir según necesidad

## Proceso de Compra

- Acceder a la página de pricing
- Proporcionar correo electrónico
- Seleccionar método de pago (tarjeta de crédito)
- Completar transacción

## Instalación del Plugin

### Pasos de instalación

1. Descargar el archivo del plugin desde tu cuenta
2. Ir a **Plugins → Agregar nuevo plugin**
3. Seleccionar **Subir plugin**
4. Hacer clic en **Seleccionar archivo**
5. Elegir el archivo descargado de Optimize Press
6. Hacer clic en **Instalar**

**Tiempo estimado**: Algunos minutos (puede variar según velocidad de internet)

### Activación del Plugin

1. Hacer clic en **Activar plugin**
2. Conectar con tu cuenta de Optimize Press
3. Ingresar correo electrónico de compra
4. Ingresar contraseña
5. El plugin realizará la conexión automática

### Instalación de componentes adicionales

1. Una vez conectado, se mostrará opción para instalar el plugin de Optimize Press
2. Hacer clic en **Instalar**
3. Esperar a que complete la instalación
4. Hacer clic en **Activar**

## Configuración Recomendada

- Activate solo la primera opción/herramienta disponible
- Esta es suficiente para comenzar
- Las demás herramientas están disponibles pero no son necesarias inicialmente
