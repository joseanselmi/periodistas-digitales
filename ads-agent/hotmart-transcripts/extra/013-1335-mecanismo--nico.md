# Clase 1335: Mecanismo Único

## Definición de Mecanismo Único

El **mecanismo único** es el posicionamiento único de ventas de tu oferta. El objetivo es que el **método de transformación sea único y diferente**.

### Diferencia: QUÉ vs CÓMO

- **QUÉ va a conseguir**: La promesa primaria (resultado deseado)
  - Ejemplo: Bajar 10 kilos en 90 días
  
- **CÓMO lo va a conseguir**: El mecanismo único (método de transformación)
  - Ejemplo: Con dieta keto
  - Ejemplo: Con dieta mediterránea
  - Ejemplo: Con zumba
  - Ejemplo: Con rutinas full body

---

## Estrategia: No Reinventes la Rueda

**Modela algo de otros idiomas que todavía no sea muy conocido en el mercado hispano.**

- Busca ofertas en otros mercados (Estados Unidos, Portugal, otros idiomas)
- Observa qué mecanismos únicos están utilizando
- Si no existe mucho en habla hispana, modelalo
- Puedes usar traductor si no sabes el idioma

## Ejemplos de Mecanismos Únicos

### 1. Las Cinco Claves para Escalar tu Negocio Digital

- **Promesa primaria**: Escalar tu negocio digital de cursos online
- **Mecanismo**: Las cinco claves
- **Estrategia**: No se inventó desde cero, se unieron cinco elementos existentes
- **Concepto**: Sin las cinco claves, es imposible escalar

### 2. La Fórmula de Lanzamiento

- **Tipo**: Entrenamiento paso a paso
- **Mecanismo**: La fórmula de lanzamiento
- **Diferencia**: Estrategia completamente diferente a Sistema de Ingresos Diarios
- **Analogía**: Como una fórmula química (detergente)
  - Paso uno
  - Paso dos
  - Paso tres
  - Paso cuatro
  - Resultado: Lanzamiento efectivo y rentable

### 3. Sistema de Ingresos Diarios

- **Objetivo**: Crear un método para tener ingresos todos los días
- **Mecanismo**: Un sistema (secuencia de pasos)
- **Funcionamiento**: Haces esto → luego lo otro → luego lo otro → sistema generando ingresos diarios
- **Base**: Pasos para trabajar con micro ofertas
- **Promesa**: Aprender a ganar **100 a 300 dólares de manera automatizada**, creando y vendiendo productos

---

## Clave para Crear Mecanismos Únicos

**No necesitas inventar nada desde cero. Únicamente:**

1. Une las piezas existentes
2. Invéntate un nombre que refleje lo que es el mecanismo único
3. Repite el sistema una y otra vez
