# Copywriting: ¿Qué es?

## Definición

El **copywriting** es el **arte y la técnica de escribir textos persuasivos** con el propósito de influir en los consumidores de manera positiva para que realicen una acción específica.

**Nota:** "Copy" y "Copywriting" son lo mismo. La primera es la abreviación.

## Principio fundamental

- Influir en los consumidores **de manera positiva**
- El objetivo siempre debe ser **ayudar a las personas**
- Resolver un **problema específico** del cliente
- Proporcionar herramientas o conocimiento que permitan pasar de un punto A a un punto B

## Acciones específicas que busca el copywriting

- **Comprar un producto** (acción principal en esta formación)
- Registrarse a un evento (clase, webinar, evento)
- Dejar correo electrónico para suscribirse a una newsletter
- Solicitar la prueba de un producto (ej: 7 días gratis de un software o plantilla)
- Hacer clic en anuncios para ir a la página de ventas
- Hacer clic para comprar en la página de ventas

## Objetivo principal de un gran copy

**"El objetivo principal de un gran copy es hacer que el prospecto se sienta comprendido."**

### Importancia de ser comprendido

- Las personas compran cuando sienten que **resuelves sus problemas**
- Genera una **gran ventaja competitiva**
- Coloca tu marca **muy por delante de la competencia**

### El error más común

- No dedicar **tiempo suficiente a investigar al cliente ideal**
- Resultado: la página de ventas no tiene sentido
- Los clientes potenciales **no se conectan** con el mensaje
- No sienten que los comprenden
- Consecuencia: **no se realizan ventas**
