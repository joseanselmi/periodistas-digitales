# Paso a Paso para Crear Micro Oferta

## ¿Qué es una Micro Oferta?

Una **micro oferta** es un **producto digital de bajo costo**, generalmente **menor a 50 dólares**, diseñado para traer clientes de manera rápida y accesible.

## Tipos de Micro Ofertas

### Ebooks
- Libros electrónicos en formato digital

### Guías
- Similares a los ebooks pero con formato diferente

### Checklists
- Listas de verificación temáticas
- Ejemplo: checklist para crear un blog y ganar dinero

### Templates
- Plantillas reutilizables para que los clientes editen
- Ejemplo: 100 templates para redes sociales
- El cliente no necesita empezar de cero

### Diarios
- Diarios de manifestación
- Diarios de agradecimiento
- Productos imprimibles
- Creables en **Canva**
- Muchos están disponibles en inglés para traducir

### Planificadores
- Planificador de hábitos
- Planificador semanal
- Planificador financiero
- Imprimibles, creables en **Canva**

### Recursos Gráficos
- Recursos para diseñadores gráficos
- Filtros y extensiones para herramientas como **Photoshop**
- Ahorran tiempo de trabajo

### Audios
- Productos con contenido de audio
- Comprobado que funcionan muy bien

### Tutoriales
- Videos enseñando cómo usar una herramienta
- Ejemplo: tutoriales para usar **AutoCAD** de manera profesional (para arquitectos)

### Mini Cursos
- Formato video
- Contenido educativo condensado
- Alternativa a cursos muy completos

## Estrategia de Combinación de Productos

**Lo recomendado es hacer una mezcla de varios tipos de productos**, no vender solo uno.

### Ejemplo de Combinación:
- 1 ebook
- + 1 checklist
- + templates
- + planificador
- + audios
- + masterclass

### Beneficios:
- **Mayor valor percibido** para el cliente
- El cliente siente que pagó mucho menos de lo que recibió
- Crear un **programa completo** más que un producto aislado

## Objetivo de una Micro Oferta

- Hacer una **pequeña promesa con gran impacto** en la vida del cliente
- Proporcionar una **ganancia rápida** al cliente
- **Motivar al cliente a comprar productos más costosos** en el futuro
- Crear una progresión hacia niveles superiores

## Estrategia a Largo Plazo

**Ganancias en el corto plazo vs. largo plazo:**
- Ganar dinero con la micro oferta inicialmente
- **Ganar más dinero a largo plazo** ofreciendo productos más costosos
- Crear una relación de cliente que compra múltiples productos progresivos
