# Clase 0625: Nombre para la Micro Oferta

## ¿Qué es el Mecanismo Único?

El **mecanismo único** es el **posicionamiento único de ventas de tu oferta**. Es el método de transformación que hace que tu oferta sea única y diferente.

### Diferencia entre Promesa Primaria y Mecanismo Único

- **Promesa primaria (el QUÉ)**: Lo que el cliente va a conseguir
  - Ejemplo: Bajar 10 kilos en 90 días

- **Mecanismo único (el CÓMO)**: El método que utilizarás para ayudar al cliente a conseguir ese resultado
  - Ejemplo: Dieta keto
  - Ejemplo: Dieta mediterránea
  - Ejemplo: Zumba (quemar grasa bailando)
  - Ejemplo: Full body (ejercicios con todo el cuerpo)

## Consejo Principal: No Inventes la Rueda

**No necesitas inventar el mecanismo desde cero.**

Modela algo de otros idiomas que todavía no sea muy conocido en el mercado hispano:

- Busca ofertas en otros mercados (Estados Unidos, Portugal, etc.)
- Observa qué mecanismos únicos están utilizando en otros idiomas
- Si esos mecanismos no se escuchan mucho en el mercado hispanohablante, modélalos
- Puedes usar traductor si no sabes el idioma

## Ejemplos de Mecanismos Únicos

### 1. Las Cinco Claves para Escalar tu Negocio Digital

- **Promesa primaria**: Escalar tu negocio digital de cursos online
- **Mecanismo**: Las cinco claves
- **Cómo se creó**: Se tomaron cinco claves que ya existen pero separadas, se unieron y se creó el mecanismo
- **Efecto**: Las personas sienten la necesidad de tener e implementar las cinco claves

### 2. La Fórmula de Lanzamiento

- **Tipo de entrenamiento**: Paso a paso para crear y lanzar productos digitales
- **Mecanismo**: Una fórmula (como en un laboratorio)
- **Concepto**: Pasos secuenciales que deben seguirse al pie de la letra
  - Paso uno → Paso dos → Paso tres → Paso cuatro → Resultado completo
- **Cómo se creó**: Unieron los pasos necesarios para un lanzamiento efectivo y rentable

### 3. Sistema de Ingresos Diarios

- **Promesa primaria**: Aprender a ganar **100 a 300 dólares** de manera automatizada
- **Mecanismo**: Un sistema de pasos secuenciales
  - Haces esto → luego haces lo otro → luego lo otro → sistema generando ingresos diarios
- **Ventaja**: Repites los pasos una y otra vez para obtener resultados

## Proceso para Crear un Mecanismo Único

1. **Identifica la promesa primaria** (el resultado que prometes)
2. **Une las piezas** existentes (no inventes de cero)
3. **Invéntate un nombre** que refleje el mecanismo
4. **Crea el sistema**: Pasos secuenciales que se repiten

## Recomendación Final

Cuando vayas a crear un nuevo producto, sigue el mismo sistema que se enseña en este curso. Tienes un sistema de pasos que puedes repetir una y otra vez para replicar el éxito.
