# Paso a paso para crear Micro Oferta

### Paso a Paso para Crear una Micro Oferta

---

### Introducción

El proceso para crear una micro oferta se compone de **10 pasos**. A lo largo del entrenamiento se van uniendo cada uno de ellos para comprender la metodología completa de creación de micro ofertas.

---

### Paso 1: Definir el Nicho de Mercado

- Un **nicho de mercado** es el grupo de personas a las cuales se les quiere vender el producto.
- Se profundiza en este concepto en los módulos siguientes.

---

### Paso 2: Definir Qué es lo que el Cliente Quiere Conseguir

- **Nunca asumir** lo que el cliente quiere.
- Error común a evitar: *"Hice este producto porque yo pienso que le puede gustar a la gente."*
- El marketing requiere una **investigación real** para entender qué quiere el cliente.
- A partir de esa investigación se crea una solución (el producto digital) que resuelve un problema concreto.

---

### Paso 3: Crear una Lluvia de Ideas de Soluciones / Posibles Productos

- Para un mismo cliente ideal existen múltiples soluciones posibles.
- Tipos de productos digitales a considerar:
  - Ebook (libro electrónico)
  - Guía
  - Checklist
  - Mini curso
  - Audio curso
- **Herramienta recomendada:** **ChatGPT** (Inteligencia Artificial) para generar ideas de productos.
  - Se profundiza en su uso en lecciones posteriores.

---

### Paso 4: Crear la Promesa Primaria de la Micro Oferta

- La **promesa primaria** es la transformación que el cliente ideal va a obtener con el producto.

**Ejemplo de promesa primaria del curso *Sistema de Ingresos Diarios*:**

```
Siguiendo el paso a paso y creando los dos tipos de productos en un año,
vas a poder construir un negocio que te genere entre $100 y $300 todos los días.
```

- Se dedican lecciones complementarias a entender cómo construir la promesa primaria propia.
- Concepto relacionado: **Propuesta de Valor** (se desarrolla en módulos posteriores).

---

### Paso 5: Definir el Mecanismo Único de la Micro Oferta

- El **mecanismo único** es el *cómo* la persona va a obtener la promesa planteada.
- Es el método o sistema específico que hace posible la transformación.

**Ejemplo del curso *Sistema de Ingresos Diarios*:**

```
Promesa:    Generar $100 a $300 diarios de manera automatizada usando IA.
Mecanismo Único: El método "Sistema de Ingresos Diarios" — un sistema de 3 pasos.
```

---

### Paso 6: Crear el Nombre para la Micro Oferta

- Una vez definidos la **promesa primaria** y el **mecanismo único**, se procede a crear el nombre del producto.
- El nombre debe reflejar:
  - La transformación que el cliente va a obtener (**promesa primaria**)
  - El método por el cual la va a obtener (**mecanismo único**)

> ℹ️ *El desarrollo completo de este paso se continúa en lecciones posteriores del módulo.*

---
