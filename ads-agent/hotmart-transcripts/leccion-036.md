# Herramientas que necesitamos

### Herramientas necesarias para crear una página web

En este video se presentan las **4 herramientas fundamentales** para crear un sitio web dentro del curso Sistema de Ingresos Diarios.

---

### 1. Hosting (Alojamiento web)

- Es el **espacio dentro de internet** donde se aloja tu sitio web
- Analogía: es como **alquilar un local en un centro comercial** para montar un negocio físico
- Ejemplo: si querés montar una tienda de zapatos, necesitás alquilar un local → el hosting cumple esa misma función, pero en internet

---

### 2. Dominio

- Es el **nombre de tu negocio** en internet
- Analogía: es como el **cartel con el nombre** que ponés arriba de tu local comercial
- Ejemplo de dominio: `sistemadeingresodiarios.com`
- Con ese dominio, las personas pueden acceder a tu sitio web (tu negocio)

---

### 3. WordPress

- Es un **gestor de contenidos**
- Permite crear:
  - Blogs
  - Páginas web
  - Sitios web
- Todo el contenido que se ve en internet puede crearse con **WordPress**

---

### 4. Constructor de sitio web (Page Builder)

- Es un **plugin/herramienta adicional** que se instala sobre WordPress
- Convierte WordPress en una **máquina más potente y optimizada**
- Analogía: WordPress funciona bien solo, pero al agregarle el constructor de sitio web es como **ponerle un turbo**
