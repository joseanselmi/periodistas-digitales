# ads-agent/playbooks — plantillas y bancos reutilizables

**Padre:** [`ads-agent/`](../README.md)

El material del que se **parte** para armar algo nuevo, para no arrancar de cero
ni repetir un ángulo ya quemado.

- `brief-template.md` — el molde de un brief de campaña.
- `copy-bank.md` — ganchos y ángulos de copy que ya se usaron, con su resultado.
- `creative-bank.md` — ideas de creativo y las que ya se probaron.
- `test-matrix.md` — qué se está testeando y contra qué control.

No confundir con [`../campaigns/`](../campaigns/README.md), que es el registro de
campañas **concretas** ya corridas.
