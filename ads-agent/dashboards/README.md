# ads-agent/dashboards — los mapas del negocio

**Padre:** [`ads-agent/`](../README.md)

Páginas HTML de una sola pieza para **mirar y entender**, no para deployar. Se
abren con doble clic desde el disco; ninguna se publica.

- `ECOSISTEMA.html` — el mapa completo del negocio: productos, dominios, por
  dónde entra y sale cada persona. Es el documento norte.
- `EQUIPO.html` — los agentes de marketing, qué hace cada uno y qué scripts corre.
- `FUNNELS.html` — los embudos activos, paso por paso.

Cuando algo cambia de verdad (un dominio, un producto, un embudo), se actualizan.
