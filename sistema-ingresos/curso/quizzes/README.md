# sistema-ingresos/quizzes — las evaluaciones del curso

**Padre:** [`sistema-ingresos/`](../../README.md)

Un test por módulo más el final. **10 preguntas cada uno, opciones A–D.**

- `quiz-modulo-1.md` … `quiz-modulo-5.md`
- `quiz-final.md`

En Hotmart se cargan como contenido de tipo **"Ejercicio"**.

Dos cosas a tener en cuenta:

- **El módulo 0 no tiene quiz** — es la bienvenida, no enseña contenido evaluable.
- **El del módulo 4 ya está escrito pero todavía no se usa**: ese módulo está
  producido y en hold. Se sube cuando salga el módulo.

El temario que evalúa cada uno sale de
[`../docs/PLAN-CURRICULUM-DEFINITIVO.md`](../docs/PLAN-CURRICULUM-DEFINITIVO.md).
