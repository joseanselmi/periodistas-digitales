# curso/docs — cómo se escribe y se produce el curso

**Padre:** [`curso/`](../README.md) · **Abuelo:** [`sistema-ingresos/`](../../README.md)

Las reglas para hacer las clases. No se sube nada de acá: es el manual interno.

## Qué se enseña

- [`PLAN-CURRICULUM-DEFINITIVO.md`](PLAN-CURRICULUM-DEFINITIVO.md) — **el vigente.**
  Qué módulo, qué clase, en qué orden y con qué arco.
- [`INDICE-CURSO.md`](INDICE-CURSO.md) — ⛔ **archivo, no leer como índice.** Es un
  plan de 12 módulos que se abandonó; el curso salió con 6 y otros temas. Lo que
  está hecho se ve en el README de cada módulo.
- [`PLAN-CURRICULUM-V2.md`](PLAN-CURRICULUM-V2.md) y
  [`PLAN-CURRICULUM-VS-LUIS-MENA.md`](PLAN-CURRICULUM-VS-LUIS-MENA.md) — las
  versiones de trabajo y el contraste con el método de Luis Mena.

## Cómo se escribe

- [`MOLDE-CLASE.md`](MOLDE-CLASE.md) — el molde de secciones y sus variantes.

## Contenido que enseña el curso

- [`IDENTIDAD-DEL-MEDIO.md`](IDENTIDAD-DEL-MEDIO.md) — cómo un medio se ve serio.
- [`MODELO-MONETIZACION.md`](MODELO-MONETIZACION.md) — el enfoque "máquina de tráfico".
- [`PLAYBOOK-CONTENIDO.md`](PLAYBOOK-CONTENIDO.md) — qué tiene que cumplir cada
  pieza para que un periódico de nicho gane en redes.

## Las tres reglas que no se negocian

1. **Solo positivo.** Nunca lo negativo, ni siquiera negándolo.
2. **Sin auto-bombo.** Nada de "esto cambia todo" o "la parte más importante".
3. **Nada del stack de Jose.** Brevo, GA4, Make no son contenido de clase; y cada
   clase usa solo lo ya enseñado en los módulos anteriores.

Todo guion pasa por el revisor de clase **y** por el agente que simula al alumno
antes de producirse. Jose aprueba el guion antes del video, y ve el video antes
de que se suba.
