# guias — el imán de republicadores

**Padre:** [`campanas/republicadores/`](../) · **Abuelo:** [`campanas/`](../../README.md)

`que-te-lean-miles` — la guía que se regala a cambio del email, en `.html`
(fuente) y `.pdf` (lo que baja el lector).

**Su URL pública es `/que-te-lean-miles.pdf`**, resuelta por un rewrite de
[`../../../vercel.json`](../../../vercel.json).

Está de este lado del repo por una razón concreta: **Vercel solo publica lo que
cuelga de `sistema-ingresos/`**. Si el PDF viviera con los agentes, el botón de
descarga del formulario de Meta no tendría de dónde bajarlo.

El racional del imán y la secuencia del embudo están en
`ads-agent/campanas/republicadores/EMBUDO-GUIAS.md`.
